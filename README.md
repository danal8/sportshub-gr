# SportsHub GR

Προσωπικό Android / desktop PWA για πρόγραμμα, αγωνιστικές, βαθμολογίες και ελληνικές μεταδόσεις. Δημόσιος κώδικας, χωρίς app store, διαφημίσεις ή analytics της εφαρμογής. Η χρήση προορίζεται για προσωπική, μη εμπορική ενημέρωση, σύμφωνα με τους όρους κάθε πηγής.

## Άνοιγμα

https://danal8.github.io/sportshub-gr/

Δεν απαιτείται λογαριασμός ή εισαγωγή αρχείων. Τα δεδομένα ζητούνται αυτόματα όταν ανοίγεις ή ανανεώνεις μια διοργάνωση. Οι απευθείας πηγές χρησιμοποιούν σύντομη προσωρινή μνήμη. Ο χρόνος ελέγχου εμφανίζεται μέσα στην κάρτα. Εμφανίζονται σκορ μόνο όταν τα επιστρέφει η πηγή: τελικό για ρητά ολοκληρωμένους αγώνες και LIVE μόνο όταν δηλώνεται ρητά από τον πάροχο. Δεν υπάρχει play-by-play. Όσο η οθόνη αγώνων είναι ορατή γίνεται έλεγχος ανά 90 δευτερόλεπτα. Δεν έχει επαληθευτεί πραγματικός αγώνας εν εξελίξει κατά τη δοκιμή.

## Εγκατάσταση

- Android: άνοιξε τον σύνδεσμο στον Chrome → ⋮ → Εγκατάσταση εφαρμογής, ή πάτησε το κουμπί Εγκατάσταση εφαρμογής.
- PC: Chrome / Edge → εικονίδιο εγκατάστασης στη γραμμή διευθύνσεων ή επιλογή εγκατάστασης από το μενού.
- Μετά την πρώτη φόρτωση, αποθηκεύονται το κέλυφος και όσα δεδομένα έχουν ήδη ανακτηθεί σε αυτή τη συσκευή. Η offline προβολή δηλώνεται ως αποθηκευμένο αντίγραφο. Τα αγαπημένα μένουν τοπικά, χωρίς συγχρονισμό μεταξύ συσκευών.

Η φυσική εγκατάσταση Android και το πάτημα εγκατάστασης στον PC δεν έχουν εκτελεστεί από τον agent. Έχουν ελεγχθεί manifest, εικονίδια PNG, mobile διάταξη και offline φόρτωση σε browser.

## Ημερήσια TV

Η τηλεόραση ανοίγει στο Σήμερα, με προηγούμενη / επόμενη ημέρα, ημερολόγιο, διοργάνωση και αναζήτηση. Ανανεώνονται αυτόματα οι ρητές μεταδόσεις από το πρόγραμμα ΕΣΑΚΕ και οι ρητοί σύνδεσμοι διαδικτυακών μεταδόσεων ΕΟΚ, μαζί με τα δηλωμένα κανάλια SL2. Το ημερήσιο πρόγραμμα Novasports διαβάζεται απευθείας στον browser με CORS· δεν αποθηκεύεται στο repo. Περιλαμβάνει μόνο ρητά δηλωμένες ζωντανές μεταδόσεις. Οι επαναλήψεις και οι αδιευκρίνιστες καταχωρίσεις αποκλείονται. Κάθε μετάδοση δείχνει άθλημα, διοργάνωση και ευδιάκριτο κανάλι. Οι πηγές φορτώνονται παράλληλα και εμφανίζονται αμέσως μόλις απαντήσει καθεμία, με άμεση επαναχρησιμοποίηση των ήδη φορτωμένων δεδομένων κατά την αλλαγή φίλτρου. Η πηγή Nova δίνει την τρέχουσα τηλεοπτική ημέρα και τις μεταμεσονύκτιες συνέχειές της· άλλες ημερομηνίες καλύπτονται μόνο από τα διαθέσιμα προγράμματα πρωταθλημάτων. Δεν συμπεραίνεται κανάλι από τα δικαιώματα μιας διοργάνωσης.

**Δεν υπάρχει πλήρης ελληνικός EPG όλων των καναλιών.** Οι επίσημοι σύνδεσμοι των καναλιών παραμένουν διαθέσιμοι. Η απουσία καταχώρισης δεν σημαίνει ότι δεν υπάρχει μετάδοση. Η δοκιμή του δωρεάν ημερήσιου ελληνικού TV endpoint TheSportsDB επέστρεψε HTTP 200 με κενό σώμα. Δεν χρησιμοποιείται ως δήθεν πλήρης τηλεοπτικός οδηγός.

## Αν μια πηγή αποτύχει

403 / 429 / αλλαγή HTML / κενά ή μερικά δεδομένα δεν παρακάμπτονται. Εμφανίζεται το αποθηκευμένο αντίγραφο με τον πραγματικό χρόνο του και σαφή ένδειξη αποτυχίας νέας ανάκτησης, εφόσον υπάρχει. Για ορισμένες διεθνείς διοργανώσεις περιλαμβάνεται περιορισμένο εφεδρικό σύνολο TheSportsDB· επισημαίνεται ως μερικό. Δεν παρουσιάζεται ως πλήρης αγωνιστική ή ως βαθμολογία.

## Τοπική λειτουργία

Χρειάζεται Node.js από https://nodejs.org/. Δεν υπάρχουν πακέτα προς εγκατάσταση.

```text
npm start
```

Άνοιξε http://127.0.0.1:4173 στον ίδιο υπολογιστή. Το ίδιο localhost δεν ανοίγει την εφαρμογή από το τηλέφωνο. Για Android χρησιμοποίησε τον HTTPS σύνδεσμο.

```text
npm test
npm run build
```

Το `dist/server/index.js` είναι το παραγόμενο Cloudflare Worker ESM. Ενσωματώνει μόνο δημόσια επιτρεπόμενα assets. Οι σελίδες του UI βρίσκονται στη ρίζα `dist/`, ο κώδικας ανάκτησης στο `worker/`. Η παραγωγή χρειάζεται Worker hosting, επειδή οι επίσημες πηγές δεν επιτρέπουν απευθείας CORS από τον browser. Το GitHub Pages φιλοξενεί το UI από το `docs/`. Για `/api/data` καλεί τον Worker στο Sites, με CORS μόνο για https://danal8.github.io. Το `node scripts/build-pages.mjs` ενημερώνει το docs/ μετά από αλλαγές. Δεν απαιτούνται κλειδιά ή μυστικά στον browser.

## Tabs

Ποδόσφαιρο / Μπάσκετ / Βόλεϊ: επιλογή διοργάνωσης του συγκεκριμένου αθλήματος. Αγώνες: συγκεντρωτική ημερήσια λίστα όλων των αθλημάτων, με ημερομηνία, φίλτρο διοργάνωσης, άθλημα και διοργάνωση σε κάθε αγώνα. Οι πηγές εμφανίζονται σταδιακά, με έως τέσσερις παράλληλες ανακτήσεις. Ποδόσφαιρο / Μπάσκετ διατηρούν το πρόγραμμα ανά αγωνιστική. Βαθμολογίες: πίνακες κατάταξης. Τηλεόραση: ημερήσιες ζωντανές μεταδόσεις.

## Προβολή

Η εφαρμογή ανοίγει στην TV. Προεπιλεγμένο σκοτεινό θέμα, συμπαγές πρόγραμμα με ώρα, αγώνα, άθλημα / διοργάνωση και κανάλι. Τα έξι tabs χωρούν χωρίς οριζόντια κύλιση. Σύρσιμο αριστερά / δεξιά πάνω στη λίστα TV ή Αγώνων αλλάζει ημέρα. Τα βέλη του ημερολογίου και τα πλήκτρα αριστερά / δεξιά προσφέρουν την ίδια λειτουργία. Οι πηγές και οι αναφορές αδειών βρίσκονται στην κλειστή ενότητα «Πηγές & ενημέρωση».

Το κουμπί εγκατάστασης κρύβεται μετά το συμβάν επιτυχούς εγκατάστασης και σε standalone λειτουργία. Η κατάσταση συγχρονίζεται μεταξύ καρτελών της ίδιας συσκευής. Αν ο browser προσφέρει ξανά εγκατάσταση, το κουμπί επανεμφανίζεται.
